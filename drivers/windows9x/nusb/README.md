# Excluded Windows USB packages

NUSB 3.20 FE, NUSB 3.6 SE and the SanDisk-based generic Win95 package are
not distributed in this repository or its release assets. No download
links or automatic download mechanism are supplied.

Their redistribution permissions have not been established. Their names
are retained only to identify the packages excluded from this distribution.
The installer contains VGA, DOS USB and CuteMouse drivers; a Windows USB
storage driver must be supplied independently under its applicable terms.
