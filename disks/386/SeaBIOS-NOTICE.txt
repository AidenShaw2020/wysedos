wyseDOS VGA modification
-----------------------
The repository's tools/vgabios/patch.py and vbe_pm.S add a VBE 2.0 protected-
mode interface and VBE/DPMS display-power control to the preserved original
SeaVGABIOS ROM. Reapplying these
sources reproduces the distributed vgabios.bin byte for byte (verified
2026-11-04). These local modifications are under the project's GPLv3 terms.

Source-provenance status
------------------------
The embedded revision identifies an upstream base, not every modification
of the original build: both ROMs say "dirty". The original complete patched
source tree, configuration and toolchain have not yet been established.
The existing tiny386 SeaBIOS patch/configuration are leads, not verified
proof of the exact original build inputs. Adding the licence texts and
this notice does not claim that the corresponding-source requirement is
fully satisfied. See LICENSES/seabios.md in the source repository.
