Excluded third-party Windows USB packages
========================================

The following packages are NOT supplied in this repository, installer or
driver bundle:

- NUSB 3.20 FE for Windows 98 First Edition, credited to Maximus Decim and
  Q@PassingBy.
- Maximus Decim NUSB 3.6 for Windows 98 Second Edition.
- Nathan Lineback's generic Windows 95 OSR2.1 USB package, based on older
  SanDisk drivers and containing Microsoft components.

No redistribution grant covering all included proprietary files has been
established. These packages are not covered by the wyseDOS GPL licence.
They have therefore been excluded from this distribution. No download
links, downloader or bundled installation files are provided for them.

A compatible, separately licensed guest driver is needed to use USB mass
storage inside Windows 9x. The supplied DOS USB drivers serve real DOS;
they do not replace a Windows driver. Choose software matching the guest
Windows edition and follow its applicable terms.
